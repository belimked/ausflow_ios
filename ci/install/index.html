First install · 首次安装

  1. Tap Install AusFlow, then Install in the pop-up. Go to the home screen and wait for the icon to finish loading. 点“Install AusFlow”，在弹窗中点“安装”，回到主屏幕等待图标下载完成。
  2. Tap the AusFlow icon once. iOS will say Developer Mode is required — tap OK. 点一次 AusFlow 图标，系统提示需要开发者模式，点“好”。
  3. Open Settings → Privacy & Security → Developer Mode, turn it on and restart the iPhone. After the restart, tap Turn On. 打开“设置 → 隐私与安全性 → 开发者模式”，开启后重启手机；重启后点“打开”。
  4. Open AusFlow and sign in with your AusFlow web console account. 打开 AusFlow，用 Web 后台的账号登录。

Updating · 更新

Open this page again and tap Install AusFlow. Your sign-in is kept. 再次打开本页点击安装即可覆盖更新，登录状态会保留。

Can't install? · 无法安装？

Only iPhones registered for this test build can install it (iOS 16.4 or later). Send your iPhone's UDID to the AusFlow team to be added. 只有已登记 UDID 的 iPhone（iOS 16.4 及以上）才能安装。如提示“无法安装”，请把手机 UDID 发给项目组登记。
