开始之前 Before you start

  • 这个版本连的是 UAT 测试环境，你录的任何数据都不会进入生产系统，可以放心操作。
    This build talks to UAT; nothing you record reaches production.
  • 测试账号由管理员提供，是 UAT 账号，不是你平时的生产账号。
    Use the UAT test account from the admin, not your production login.
  • 核对结果时用 UAT 的网页后台：uat.ausflow.saulxj.ggff.net（同一账号可登录）。
    Check results in the UAT web console with the same account.
  • 每一项：能完成就打勾；不能就记下 手机型号、时间、做了什么、看到了什么，最好截图。见最后的反馈模板。
    Tick each item, or note phone model, time, what you did and what you saw (screenshot if you can).

0 安装 Install

  1. 用 iPhone 的 Safari（不要用微信或其他浏览器）打开 belimked.github.io/ausflow_ios，点 Install，确认安装。
    Open the install page in Safari on the iPhone and tap Install.
  2. 第一次装的手机：设置 → 隐私与安全性 → 开发者模式 → 打开，重启手机，再打开 App。
    First install on this phone: Settings → Privacy & Security → Developer Mode → on, restart.
  3. 打开 App，登录页底部应显示 UAT environment；"我" 页 → App version 应为 1.1.0。
    The sign-in screen shows "UAT environment"; Me → App version is 1.1.0.
装不上或提示"无法验证"：先确认手机已在管理员那里登记过（UDID），再重试。
If it will not install or says it cannot be verified, make sure the admin has registered this phone (UDID) first.

1 登录 Sign in

  • 用户名 + 密码登录；"Remember my username" 开关有效（登出再进，用户名还在）Sign in; with "Remember my username" on, the username is kept after signing out.
  • 故意输错密码 3 次 → 提示账号锁定 15 分钟；15 分钟后能正常登录3 wrong passwords → "locked for 15 min"; sign-in works again afterwards. Use a spare test account for this.
  • "Forgot password?" → 账号邮箱收到重置链接 → 在浏览器里设新密码 → 用新密码登录 AppReset link arrives by email; set a new password in the browser; the new password works in the app.
没有登记邮箱的账号收不到重置邮件，这是预期行为；请管理员先在后台给账号填上邮箱。
Accounts without an email address get no reset email (by design).

2 上车 Join a vehicle

  • 首页 "Choose driver & vehicle" → "Scan vehicle sticker" 扫车辆贴纸（VH… 码）→ 自动带出公司和车辆Scan the vehicle sticker; the company and vehicle are filled in.
  • 在 "Registration" 框输入车牌的一部分 → 列表里点选 → 自动带出公司Find the vehicle by typing part of the registration.
  • 保存后首页出现 "ON BOARD · 车牌" 余量卡片（新车应为 0 L）Today shows the on-board card for the vehicle.
  • 车上有料时换车 → 弹出"余量留在原车"的提醒Changing vehicle while loaded warns that the waste stays on the old vehicle.

3 收料 Pickup

  • 首页 "Scan device QR" 扫设备二维码 → 设备页 → "Start pickup"（会请求定位权限，选"使用期间允许"）Scan the device QR → Start pickup (allow location while using).
  • 二维码扫不了时 "Enter code manually" 输入设备编号也能找到设备Manual code entry finds the device too.
  • 完成：填体积（试试 +/−50 和百分比快捷键）、选废物类型、选 "Planned destination"、拍 1 张照片、写备注 → CompleteFinish with volume, waste type, planned destination, one photo and a note.
  • 后台核对：web 后台该清运记录能看到照片、目的设施、体积、GPS 距离Console: the pump-out shows the photo, destination, volume and distance.
  • 首页余量增加；点余量卡片进入车载清单，这单在列表里On-board volume goes up; the pickup is in the on-board list.
  • 设备页 "Service only · no waste collected" → 记录一次 0 L 服务，设备"上次服务"日期更新Service-only records a 0 L visit and updates last service.
  • 开一单后在完成页点 "Cancel pickup" → 这单被删除，设备页恢复可开单Cancel removes the pickup.
距设备超过 200 米完成、或体积超过设备容量时，App 会提示并在记录上打标记，这是正常的。
Finishing more than 200 m from the device, or above its capacity, is flagged — by design.

4 问题上报 Report a problem

  • 设备页 → "Report a problem" → 选分类（如 No access）、写描述、拍照 → "Report problem"Category, description, photo → Report problem.
  • 分类选 "Other" 时不填描述，按钮应为灰色不可点"Other" needs a description before the button enables.
  • 后台核对：web 后台该设备的 Reported Issues 里有这条和照片；设备页 "Problems" 也显示它Console and the device screen both show the problem and photo.

5 卸料与转料 Offload and transfer

  • 首页 "Offload waste" → "Scan facility plate" 扫设施牌（FA… 码），或在列表选附近设施 → 确认量（默认是车上余量）→ DeliverOffload at a facility; the volume defaults to what is on board.
  • 成功页显示 "Nothing left on board"；首页余量归零On-board goes to 0 L.
  • 再收一单 → 首页余量卡片 → "Transfer to another vehicle" → 选本公司另一台车 → Transfer all wasteTransfer the whole load to another company vehicle.
  • 目标车装不下时（超过罐容量）会先弹确认Over-capacity transfers ask for confirmation.
  • History 页 → Offloads / Transfers 分类能看到这两条；web 后台 Unloads / Transfers 也有Both appear under History and in the console.

6 离线 Offline

  • 先在线登录一次 → 开飞行模式 → 扫码开单 → 完成（带照片）→ 首页顶部显示 "OFFLINE · 2"（或类似数字）Airplane mode → start and finish a pickup → Today shows "OFFLINE · N".
  • 离线时这单在 History 里能看到，标题显示 "Waiting to sync"The pickup is visible with "Waiting to sync".
  • 离线时杀掉 App 再打开 → 待发记录还在Kill and reopen the app while offline; the queued pickup is still there.
  • 关飞行模式 → 顶部变成 SENDING → 消失；"我" → Sync 显示 "Up to date"Back online it sends by itself; Me → Sync says "Up to date".
  • 后台核对：web 后台能看到这单和照片，编号已变成正式的 PK 编号Console shows the pickup and photo under a real PK id.
如果同步后 "我" → Sync 里出现红色条目，说明服务器拒绝了这条记录（例如别人已在同一设备开单）。点开它，选 "Try again" 或 "Discard"，并把提示文字告诉我们。
A red item under Me → Sync means the server refused that record; open it, choose Try again or Discard, and report the message.

7 拖车（演示）Trailers (demo)

  • 首页 "TRAILERS · DEMO" → Attach trailer → 挂一台拖车；收料完成页出现 "Collect into" 可选装入拖车Attach a demo trailer; the finish form offers "Collect into" the trailer.
  • 请回答：现场实际作业用不用拖车/挂车？怎么用？Tell us whether trailers are really used in the field and how.
拖车只是演示，数据只存在手机上，不会上传。你的反馈决定它要不要做成正式功能。
Demo only: trailer data stays on the phone. Your feedback decides whether it becomes a real feature.

8 账号 Account

  • "我" → "My details" → 改名字（需输入当前密码）→ 首页问候语变成新名字Change your name with the current password; Today greets you by the new name.
  • "My details" → 改密码 → 登出 → 用新密码登录Change the password, sign out, sign in with the new one.
  • "我" → Refresh data 能刷新；Sign out 有二次确认Refresh works; Sign out asks for confirmation.

已知限制 Known limits

  • 拖车数据不上传服务器。Trailer data stays on the phone.
  • 离线使用前需要先在线登录过一次。One online sign-in is needed before working offline.
  • 登录有效期 12 小时；离线时过期不会丢失待发记录，联网后重新登录即可继续发送。Sessions last 12 hours; queued work survives, sign in again to send it.
