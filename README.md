# AusFlow iOS

Driver app for recording grease trap pickups. Expo SDK 58 (React Native), talks to the **UAT** AusFlow API (`src/lib/config.ts`).

Features: sign in with an AusFlow web console account, choose transport company / driver / vehicle, scan a device QR code (or enter it manually), start a pickup with GPS, finish it with the volume collected, browse devices (overdue, nearby) and pickup history.

## Develop

```bash
npm install
npx expo start          # needs a development build on device; Expo Go lacks some native modules
npm run typecheck
npm run lint
```

`ios/` is generated by `npx expo prebuild` and is not committed. Configure native settings in `app.json`.

## Ad Hoc builds (GitHub Actions)

Every push to `main` (or a manual run of **iOS Ad Hoc**) builds a signed IPA on a macOS runner and publishes the install page to GitHub Pages: <https://belimked.github.io/ausflow_ios/>. The IPA is also kept as a workflow artifact for 30 days.

Repository secrets:

| Secret | Content |
| --- | --- |
| `IOS_DIST_P12_BASE64` | Apple Distribution certificate + private key (`.p12`), base64 |
| `IOS_DIST_P12_PASSWORD` | Password of the `.p12` |
| `IOS_ADHOC_PROFILE_BASE64` | Ad Hoc provisioning profile for `com.ausflow` (`.mobileprovision`), base64 |

Team ID `8J42Q87M5P` and bundle ID `com.ausflow` are set in the workflow.

### Adding a test iPhone

1. developer.apple.com → Devices → register the iPhone's UDID.
2. Profiles → edit the Ad Hoc profile, tick the new device, save and download it.
3. Replace `IOS_ADHOC_PROFILE_BASE64` with `base64 -w0 profile.mobileprovision` and re-run the workflow.

On iOS 16+ testers must enable **Settings → Privacy & Security → Developer Mode** once (the install page explains this).
